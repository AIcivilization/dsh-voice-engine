# 声音引擎 dsh-voice-engine

DeepSeek Harness（dsh）的声音插件。讯飞、Edge、本机 Ming 三家声音装在一起，三种用法：

| 谁用 | 怎么用 |
|---|---|
| **你自己** | 音色库里输入文字点「朗读」；或者在对话里说「把这段读出来」「给这份文案配旁白，要字幕」 |
| **DSH 里的其他插件** | `ctx.inject(['voiceEngine'], (c) => c.voiceEngine.speak('你好'))`，不用自己接语音服务 |
| **你正在开发的其他程序** | 调本机接口，或 `import { speak } from 'dsh-voice-engine/sdk'`，一行出声音 |

别的产品涉及声音时，不用再自己写语音代码，引用声音引擎就行。接入说明见 [docs/声音引擎接口.md](docs/声音引擎接口.md)。

> 当前版本 0.6.0。原名 dsh-xfyun，第一次启动会自动把原来的凭据、设置和缓存复制过来。

## 讯飞音色能自己查错改错

模型听不到声音，但讯飞超拟人合成会返回每个字实际的读音和时长。插件把这些信息交给模型，于是它能发现这样的错误：

```
CEO说AI的API调[tiao2]用量翻了一倍      ← 模型发现「调用」读错了
CEO说AI的API调[=diao4]用量翻了一倍     ← 自动加标注重新合成
CEO说AI的API调[diao4]用量翻了一倍      ← 再查一遍，读对了
```

这段例子来自真实测试。

## 安装

先完全退出 DSH（macOS 按 Cmd+Q），再运行：

```bash
dsh plugin --profile desktop add dsh-voice-engine
```

然后：

1. 打开 **设置 → 声音引擎**，填写 APPID、APISecret、APIKey，它们在[讯飞控制台](https://console.xfyun.cn)语音服务页的右上角。
2. 点 **保存并检测**。检测不通过时，页面会告诉你下一步做什么。

需要在讯飞控制台开通：

| 服务 | 用途 | 入口 |
|---|---|---|
| 极速录音转写 | 音频和视频转文字、字幕 | [服务页](https://console.xfyun.cn/services/ost) |
| 超拟人合成 | 主力引擎，有读音反馈 | [领取字符量](https://console.xfyun.cn/sale/buy?wareId=9134&packageId=9134001&serviceName=%E8%B6%85%E6%8B%9F%E4%BA%BA%E5%90%88%E6%88%90&businessId=uts)、[服务页](https://console.xfyun.cn/services/uts) |
| 在线语音合成 | 方言和部分外语音色 | [服务页](https://console.xfyun.cn/services/tts) |

音色授权和字符量是两项独立的权限，都要有。

输出 mp3 需要 `ffmpeg`，没有时输出 wav。

## 怎么用

直接在对话里说：

| 你说 | 场景 |
|---|---|
| 给这份文案配个沉稳的旁白，要字幕 | S01 旁白 + 字幕 |
| 改成 60 秒口播，活泼点，要卡点字幕 | S02 口播 + 卡点字幕 |
| 第三句语气再正式点 | S03 改稿增量重配 |
| 把这段录音转成文字 | S14 音频转文字 |
| 给这个视频出字幕 | S15 视频转字幕 |
| 把录音整理成会议纪要 | S16 会议纪要 |
| 把这期节目改写成文章 | S17 播客转文章 |
| 按话题整理采访，标出时间点 | S18 采访整理 |
| 查这批录音有没有违规话术 | S19 录音质检 |
| 把字幕翻成英文 | S20 字幕翻译（模型翻译，不扣讯飞额度） |
| 把这段读出来 | S08 一键朗读 |
| 这张表的提示语都生成音频 | S13 语音包批量生成 |
| 看看有哪些粤语音色 | S21 音色查询试听 |
| 这几个音色读这句对比下 | S22 用我的文案试音 |
| 科技宣传片用哪个音色好 | S23 按场景推荐音色 |

音频默认保存到当前工作目录的 `voice-output/`。

### 配音工程

做带字幕的成片时，模型会建一个工程，放在 `voice-output/<工程名>/`：

- **改一句只重配一句。** 其余句子复用，不扣量，时间轴和字幕整体重排。
- **字幕显示原文。** 「2024年」读成「二零二四年」，字幕仍然是「2024年」。时间来自音素时长，精确到每个字。
- **读音修正放进工程词表。** 不改文稿，字幕也不带标注。
- **自动检查。** 每次导出都查时长是否达标、有没有漏读或多读。
- **导出格式：** mp3、wav、SRT、VTT、ASS，ASS 支持逐字变色的卡点字幕和竖屏排版。

`manifest.json` 保存文稿和每句的合成记录，可以直接打开看。

### 转写

转写结果放在 `voice-output/<文件名>-转写/`，有 txt、srt、vtt 和带时间、说话人的 json。

- **同一个文件不重复扣费。** 任务号和结果都存在本机，中断了、等太久了，再发一次就接着等。
- **超过 30 分钟先问你。** 时长读不出来时，超过 200M 先问你。
- **视频只传音轨。** 用 ffmpeg 抽出音频再上传，视频本身不上传。
- **说话人只分得出不是同一个人，** 不知道是谁，所以显示「说话人1」。

### 命令

这些命令不走模型、不花 token：

| 命令 | 作用 |
|---|---|
| `/voice-help` | 命令和场景清单 |
| `/voice-doctor` | 一步步检查为什么用不了 |
| `/voice-list <关键词>` | 打开音色库，试听、对比、选用 |
| `/voice-default <音色>` | 设默认音色，`--off` 恢复自动选择 |
| `/voice-say <文字>` | 朗读 |
| `/voice-try <音色,音色> <文字>` | 多个音色对比 |
| `/voice-batch <清单文件>` | 批量语音包，先出计划，加 `--yes` 才执行 |
| `/voice-listen <文件> [--speakers]` | 音频视频转文字和字幕 |
| `/voice-allow <名字>` | 在当前对话放行别的语音产品，`--off` 恢复 |

### 三家声音

| 引擎 | 花钱吗 | 说明 |
|---|---|---|
| 讯飞 | 扣讯飞额度 | 超拟人音色返回实际读音，模型能自己查错改错；配音工程、字幕都靠它 |
| Edge | 免费 | 微软的在线语音，要联网。用别的插件（听懂、有声书）已经装好的 edge-tts；没有的话在音色库里一键安装 |
| Ming | 免费 | 在本机合成，不联网，只支持 Apple 芯片的 Mac。用 dsh-her 或「听懂」装好的本机 Ming，不重新下载 |

对模型说「用免费的声音读」「用晓晓读」就行。Edge、Ming 没有读音反馈，查不了多音字。

### 音色库

发 `/voice-list`，或在对话页右侧栏选「声音引擎」。讯飞、Edge、Ming 分三栏，讯飞那栏很长，可以折叠：

- **找：** 按名字、用途、声线、语种、方言筛选，也可以只看有免费样音的。
- **听：** 听之前就标明花不花钱。有免费样音的直接放；没有样音的要合成一句，会写明约扣多少字，听过的不再扣。
- **对比：** 给几个音色点「对比」（最多 5 个），写一句自己的文案连续试听。扣多少字写在按钮上，点了才花。
- **选：** 点「选用」设为默认音色，之后不指定音色时都用它，不用经过模型。也可以发 `/voice-default <音色>`，或对模型说「以后都用某某」。

模型推荐音色时，候选会出现在输入框上方，同样能试听和对比，点「选这个」后选择发回对话。

## 启用后优先用声音引擎

配置好凭据后，语音合成和转写需求会优先走本插件：

- 模型不会去网上找别的产品，也不会运行或安装 `edge-tts`、`say`、`piper`、`whisper` 等工具。
- 讯飞失败时不会悄悄换别家，会说明原因并询问你。
- **其他插件不受影响**，比如 dsh-audiobook 内部用的 Edge TTS。
- 想在某个对话里用别的工具，发 `/voice-allow <名字>`。想彻底关闭，到设置页取消勾选。

目前只拦截语音合成和转写。翻译、OCR 还没做好，这类工具不受影响。

## 隐私和费用

- 凭据只保存在本机 `~/.dsh/dsh-voice-engine/credentials.json`，权限 600，不会发给模型和浏览器。
- 合成的文字和转写的音频会发给讯飞。
- 一次超过 2000 字会先问你，阈值可以在设置页改。
- 合成过的内容有本地缓存，不重复扣量。
- 设置页显示的字数是本机统计，不是讯飞账户余额。

## 已知限制

- 单次合成上限：超拟人约 60KB，`v2/tts` 约 7900 字节。长文请用配音工程，它按句合成。
- 读音检查和标注只对超拟人音色有效。`v2/tts` 音色的字幕，句子时段来自音频长度，句内按字数估算，导出结果会标明。
- 卡点字幕只有 ASS 有；导入不支持 ASS 的剪辑软件时用 SRT，没有逐字变色。
- 工程导出是一次工具调用，很长的文稿（比如整本书）留到 M5 的长任务。
- `字[=拼音]` 标注来自实测，没有在官方文档里见到，讯飞改动时可能失效。
- 转写只支持普通话和英文。文档写明转写接口 `language` 只有 `zh_cn`，粤语和外语要等接入录音文件转写（它需要另一个 SecretKey）。
- 转写的词时间比配音的音素时间粗，字幕可能差零点几秒。
- 回听查得出漏读、多读，查不出同字异音，读音要看合成返回的拼音。
- 只支持配了凭据的本机使用，暂未在其他系统上测试。

## 给别的产品用

插件运行时在本机开一个接口（`127.0.0.1`，要带令牌），别的插件、脚本、产品都能调。地址和令牌在 `~/.dsh/dsh-voice-engine/engine.json`：

```bash
curl -s "$URL/v1/speak" -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"text":"你好","voice":"edge:zh-CN-XiaoxiaoNeural"}' -o hello.mp3
```

用哪几家声音在设置页的「声音引擎接口」里勾选，没勾的那家 DSH 里和接口都不用。讯飞默认不对外开放，免得别的程序花你的额度，要用到卡片的详细里打开。不开 DSH 也能用：`npx dsh-voice-engine serve`。完整说明、Python 和 Node 例子见 [docs/声音引擎接口.md](docs/声音引擎接口.md)。
