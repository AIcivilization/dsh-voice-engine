# 声音引擎接口

装了 dsh-voice-engine（声音引擎），本机就有了讯飞、Edge、Ming 三家的声音。别的 dsh 插件、你自己写的脚本、别的产品，都可以直接引用它，不用再自己接语音服务。

三种接入方式，挑一种：

| 你是 | 用 | 写多少 |
|---|---|---|
| DSH 里的另一个插件 | `voiceEngine` 服务 | 一行 |
| Node.js 程序 | `dsh-voice-engine/sdk` | 一行 |
| 任何语言、任何程序 | 本机 HTTP 接口 | 一个请求 |

## 三家怎么选

| 引擎 | 花钱吗 | 要联网吗 | 适合 | 限制 |
|---|---|---|---|---|
| 讯飞 | 扣你的讯飞额度 | 要 | 要求读音准确的成品。超拟人音色能返回实际读音 | 默认不对外开放，要你在设置页打开 |
| Edge | 免费 | 要，文字发到微软 | 日常朗读，中英文、粤语、几种方言 | 不是微软的正式接口，可能失效 |
| Ming | 免费 | 不要，在本机合成 | 离线、不想把文字发出去 | 只支持 Apple 芯片的 Mac；要先在 dsh-her 或「听懂」里装过本机 Ming |

用哪几家由用户决定：在 DSH「设置 → 声音引擎 → 声音引擎接口」里勾选。只要讯飞就只勾讯飞，只要免费的就只勾 Edge 和 Ming，默认三家都勾。没勾的那家，DSH 里的 AI、音色库和这个接口都不用。讯飞会扣额度，勾选之外还要在卡片的详细里打开「允许别的产品用讯飞」（默认关）。接口里不能用的来源不出现在音色列表里，合成会返回 403。

## DSH 插件：直接用 `voiceEngine` 服务

装了声音引擎的 DSH 里，别的插件这样用（做法和 dsh-her 的 `herVoices` 一样）：

```js
ctx.inject(['voiceEngine'], async (c) => {
  const { audio, format, engine } = await c.voiceEngine.speak('你好，欢迎收听。', { voice: 'edge:zh-CN-XiaoxiaoNeural' })
  // audio 是 Buffer；format 是 mp3 或 wav
})
```

还有 `c.voiceEngine.voices({ engine, q, gender, lang })` 和 `c.voiceEngine.engines()`。没装声音引擎时回调不执行，你的插件照常运行。规则和 HTTP 接口一样：只能用设置页勾选的来源，讯飞还要用户另外允许。

## Node.js 程序：`dsh-voice-engine/sdk`

```bash
npm install dsh-voice-engine
```

```js
import { speak, voices, available } from 'dsh-voice-engine/sdk'

if (await available()) {
  await speak('你好，欢迎收听。', { voice: 'ming:灵小雅', out: 'hello.mp3' })
}
```

SDK 自己读地址和令牌。出错时抛 `VoiceEngineError`，带 `kind` 和 `hint`。

## 任何程序：本机 HTTP 接口

### 三步接入

**1. 打开接口。** DSH 开着时自动运行。在「设置 → 声音引擎 → 声音引擎接口」能看到地址，也可以在那里关掉。不开 DSH 时，在插件目录运行：

```bash
npx dsh-voice-engine serve
```

**2. 读地址和令牌。** 都在 `~/.dsh/dsh-voice-engine/engine.json`：

```json
{ "url": "http://127.0.0.1:18321", "token": "…" }
```

**3. 调用。** 每个请求带上 `Authorization: Bearer <token>`。

先试一下能不能用（一条命令，存到桌面）：

```bash
python3 -c "import json,os,urllib.request as u;c=json.load(open(os.path.expanduser('~/.dsh/dsh-voice-engine/engine.json')));r=u.Request(c['url']+'/v1/speak',data=json.dumps({'text':'你好，欢迎收听。','voice':'edge:zh-CN-XiaoxiaoNeural'}).encode(),headers={'Authorization':'Bearer '+c['token'],'Content-Type':'application/json'});open(os.path.expanduser('~/Desktop/hello.mp3'),'wb').write(u.urlopen(r).read());print('已存到桌面 hello.mp3')"
```

或者运行 `npx dsh-voice-engine check`，它会逐项检查并合成一句。

下面的 curl 例子要在**同一个终端里连着运行**，第一段设的变量第二段才用得上：

```bash
URL=$(python3 -c "import json,os;print(json.load(open(os.path.expanduser('~/.dsh/dsh-voice-engine/engine.json')))['url'])")
TOKEN=$(python3 -c "import json,os;print(json.load(open(os.path.expanduser('~/.dsh/dsh-voice-engine/engine.json')))['token'])")

curl -s "$URL/v1/speak" -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"text":"你好，欢迎收听。","voice":"edge:zh-CN-XiaoxiaoNeural"}' -o hello.mp3
```

## 接口

### `POST /v1/speak` 合成

请求体（JSON）：

| 字段 | 说明 |
|---|---|
| `text` | 必填。要读的文字。讯飞一次最多按设置页的确认阈值（默认 2000 字），Edge、Ming 一次最多 3000 字 |
| `voice` | 音色编号，见下一节。不填用你在音色库里选的默认音色 |
| `speed` | 语速倍数，0.5 到 2，默认 1。Ming 不支持调速，会按正常语速读 |
| `format` | `mp3`（默认）或 `wav`。没装 ffmpeg 时讯飞和 Ming 只能给 wav |

成功时直接返回音频。响应头里有：

| 头 | 含义 |
|---|---|
| `x-voice-engine` | `xfyun`、`edge` 或 `ming` |
| `x-voice-id` | 实际用的音色编号（URL 编码） |
| `x-voice-format` | 实际格式 |
| `x-voice-duration-ms` | 音频时长，毫秒 |
| `x-voice-charged-chars` | 这次扣了多少讯飞字数，Edge、Ming 是 0 |
| `x-voice-cached` | 是否用了缓存。同样的内容第二次不重新合成，讯飞也不重复扣费 |

### `GET /v1/voices` 查音色

参数都可选：`engine`（`xfyun`、`edge`、`ming`）、`q`（名字、用途、方言）、`gender`（`female`、`male`、`child`）、`lang`（`zh`、`en`、`yue`……）、`limit`。

```bash
curl -s "$URL/v1/voices?engine=edge&lang=zh" -H "Authorization: Bearer $TOKEN"
```

返回 `{ ok, total, voices: [{ id, name, engine, gender, lang, dialect?, style?, status, free }] }`。`id` 就是 `/v1/speak` 的 `voice`。

### `GET /v1/engines` 三家现在能不能用

返回每家的 `ready`，用不了时有 `reason`（原因）和 `fix`（怎么办）。每家都有 `open`，表示这一家现在能不能通过接口用（勾选了；讯飞还要打开「允许别的产品用讯飞」）。

### `GET /v1/health` 接口在不在

不用令牌。返回 `{ ok: true, name: "dsh-voice-engine", version }`。

## 音色编号

| 引擎 | 写法 | 例子 |
|---|---|---|
| 讯飞 | `xfyun:` 加讯飞编码 | `xfyun:x6_lingfeihan_pro`（聆飞瀚） |
| Edge | `edge:` 加 Edge 声音名 | `edge:zh-CN-XiaoxiaoNeural`（晓晓）、`edge:en-US-AndrewNeural` |
| Ming | `ming:` 加声音名 | `ming:灵小雅` |

也可以只写名字，比如 `晓晓`、`灵小雅`、`聆飞瀚`。完整列表用 `/v1/voices` 查，或者在 DSH 对话页右侧栏的「声音引擎」里试听。

## 出错时

返回 JSON：`{ ok: false, kind, error, hint }`。`hint` 写着怎么办。

| HTTP | kind | 含义 |
|---|---|---|
| 400 | `param`、`too-long` | 参数不对、文字太长 |
| 401 | `token` | 令牌不对 |
| 403 | `xfyun-closed` | 讯飞没有对外开放。到设置页勾选讯飞并打开「允许别的产品用讯飞」，或换 Edge、Ming |
| 403 | `engine-closed` | 用户没勾选 Edge 或 Ming。到设置页勾选，或换已开放的来源 |
| 403 | `host` | 不是从本机地址访问 |
| 502 | `engine`、`network`、`credentials`、`service`、`voice` | 引擎本身出错，看 `hint` |

## 各种语言怎么调

**Node.js**

```js
import { readFileSync, writeFileSync } from 'node:fs'
import { homedir } from 'node:os'

const { url, token } = JSON.parse(readFileSync(`${homedir()}/.dsh/dsh-voice-engine/engine.json`, 'utf8'))
const res = await fetch(`${url}/v1/speak`, {
  method: 'POST',
  headers: { authorization: `Bearer ${token}`, 'content-type': 'application/json' },
  body: JSON.stringify({ text: '你好，欢迎收听。', voice: 'ming:灵小雅' }),
})
if (!res.ok) throw new Error((await res.json()).error)
writeFileSync('hello.mp3', Buffer.from(await res.arrayBuffer()))
```

**Python**

```python
import json, os, urllib.request

cfg = json.load(open(os.path.expanduser("~/.dsh/dsh-voice-engine/engine.json")))
req = urllib.request.Request(
    cfg["url"] + "/v1/speak",
    data=json.dumps({"text": "你好，欢迎收听。", "voice": "edge:zh-CN-YunxiNeural"}).encode(),
    headers={"Authorization": "Bearer " + cfg["token"], "Content-Type": "application/json"},
)
open("hello.mp3", "wb").write(urllib.request.urlopen(req).read())
```

**别的 dsh 插件**：在插件的 host 端代码里照 Node.js 的写法调就行。先 `GET /v1/health`，接口不在时告诉用户装 dsh-voice-engine，或退回自己的方案。

**命令行**：不想写代码时：

```bash
npx dsh-voice-engine voices --engine ming
```

```bash
npx dsh-voice-engine say "你好，欢迎收听。" --voice ming:灵小雅 --out hello.mp3
```

## 安全

- 只监听 `127.0.0.1`，别的电脑连不上。
- 令牌只存在 `engine.json`，权限 600。要换令牌：删掉这个文件，重启 DSH。
- 讯飞默认不对外开放，免得别的程序悄悄花你的额度。用哪几家在设置页勾选。
- 讯飞的凭据不经过接口，别的产品拿不到。
