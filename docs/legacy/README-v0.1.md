# dsh-xfyun

讯飞语音能力接入 dsh 的插件项目。当前进度：**音色数据 + 音色页**。

```
dsh-xfyun/
├── 音色库.html          单文件页面，双击即开（86 KB，无外部依赖）
├── build_page.py        从 data/voices.json 生成页面的构建脚本
├── build_data.py        从三个公开数据源重建 voices.json
├── 项目文档.md          完整技术文档：架构、数据模型、代码说明、开发计划
└── data/
    ├── voices.json      235 条音色，code 为主键（65 KB，插件运行时读这个）
    ├── voices.pretty.json 缩进版，调试用
    └── README.md        字段说明 + 用法示例
```

## 音色库.html

双击用浏览器打开即可。音频是远程 CDN，需要联网。

**功能**

| 功能 | 说明 |
|---|---|
| 双视图 | 卡片（重听觉）/ 表格（重信息），顶部切换，选中态跨视图共享 |
| 搜索 | 中文名 / 拼音全拼 / 拼音首字母 / 发音人编码，实时过滤，中文命中高亮 |
| 可用性筛选 | 能听能用 100 / 全部 235 / 仅能用 58 / 仅能听 17 / 需开通 60 |
| 声线筛选 | 女声 / 男声 / 童声 |
| 语种筛选 | 25 种语言与方言（中文、英语、粤语、四川话、维吾尔语、藏语…） |
| 场景筛选 | 通用、语音助手、阅读听书、新闻播报、多语种、智能客服… |
| 试听 | 点卡片或行内播放键，单例播放（同时只播一个），卡片底部有进度条 |
| 选中 | 点卡片/行选中，底部固定条显示名称 + 编码，可复制编码 |
| 快捷键 | `/` 或 `⌘K` 聚焦搜索，`Esc` 清空 |

**设计要点**

- **可用性徽标是页面的核心**：🟢 能听能用 / 🟠 仅能用 / 🔵 仅能听 / ⚪ 需开通。这一列直接告诉用户下一步该做什么，避免「试听半天发现用不了」
- **默认只显示 100 个能听能用的黄金子集**，其余按需切换
- **表格视图也保留播放键**，不是只有卡片能听
- 浅色/深色自动跟随系统
- 窄屏（≤640px）卡片单列、按钮铺满，≤430px 进一步压缩标题栏

## 重新生成页面

改完数据后：

```bash
pip3 install --user pypinyin   # 仅首次
python3 build_data.py          # 重建 voices.json（读原始素材）
python3 build_page.py          # 重建 音色库.html
```

数据来自 `data/voices.json`，页面生成时内联进去，所以改数据必须重新构建。

详细的技术说明见 `项目文档.md`。
