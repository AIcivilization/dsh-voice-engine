# S01 宣传片旁白 + 字幕

用户有一份文案，要配音和字幕。

1. **定音色。** 用户指定了就用。否则用 `voice_voices` 查 `scene` 相关、`status` 是 `ok` 的超拟人音色，挑 3 个用 `action=present` 发给用户试听，然后结束这一轮等用户选。用户说「随便」或已经选过时不要再问。
2. **按语义断句。** 一句不要太长，意思完整，读起来能换气。文案里的数字、英文缩写、专有名词原样保留，不用改写。不要改用户的文案，要改先问。
3. **建工程。** `voice_project`，`action=create`，传 `name`、`sentences`、`vcn`。用户提了时长就传 `targetSeconds`。
4. **导出。** `action=build`，默认带 SRT。用户要别的字幕格式就传 `formats`。
5. **查结果。**
   - `pronunciation`：按总 skill 的规则查读音。读错了不要改文稿，用 `action=edit` 传 `glossary`，如 `{"调用":"调[=diao4]用"}`，然后再 `build`。只有含这个词的句子会重配。
   - 时长检查不通过：差得少就调 `speed`（调整后整个工程都要重配，先说明）。差得多就精简句子，问过用户再改。
   - 覆盖检查不通过：看提示。「可能漏读」「读音里有原文没有的内容」要认真看，数字和符号的读法可能不符合预期，用词表或改写解决。
6. **交付。** 告诉用户文件路径、总时长、扣了多少字。改过读音就说明改了什么。

修正最多两轮。两轮还没解决，把问题告诉用户。

你听不到声音，不要评价音色好听不好听。

验收：有音频和字幕；时长符合要求；读音没有错；字幕显示的是原文。
