# S16 会议纪要

1. `voice_listen` 转写，传 `speakers: true`。知道人数就传 `speakerCount`，有专有名词就传 `hotwords`。
2. 用文件读取工具读 `txt`。不要只看工具返回的开头。
3. 写纪要，存成 Markdown 放在转写结果的同一目录：议题、结论、待办（谁、做什么、何时）。每条结论和待办标上时间点，方便回查。
4. **讯飞只分得出是不是同一个人，不知道是谁。** 说话人写「说话人1」，内容能确认身份时才写名字，并说明依据。
5. 原文没提到的负责人和日期写「未明确」，不要猜。

验收：逐字稿和纪要都有；每条待办能在逐字稿里找到出处。
