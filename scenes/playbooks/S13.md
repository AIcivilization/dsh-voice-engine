# S13 语音包批量生成

用户有一张提示语清单，比如 IVR 语音、游戏台词、课堂提示音，要逐条生成音频文件。

清单文件每行一条，支持两种写法：

```
welcome,您好，欢迎致电
仅文本的一行也可以，文件名按序号生成
```

以 `#` 开头的行和空行会跳过。

1. 用户给的是表格或别的格式时，先整理成上面的文本文件。
2. 用户没指定音色时，先用 `voice_voices` 选一个已授权的，并告诉用户选了谁，整批用同一个音色。
3. 调用 `voice_scene`，`action=run`，`id=S13`，传 `file`。字数超过确认阈值时，插件会请用户确认。
4. 看返回的每条结果：
   - `readings` 里有多音字读错的，把清单里那一行改成 `字[=拼音]` 再跑一次。已合成的不会重复扣量。
   - `failed` 不为空时，把原因告诉用户。
5. 告诉用户输出目录、成功和失败的条数。

验收：每条都有对应文件；没有读错的多音字。
