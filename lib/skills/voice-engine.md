# 用声音引擎做语音

`dsh-voice-engine`（声音引擎）插件让你操作三家声音：讯飞（主力，能查读音）、Edge、Ming（免费）。你是制作人：判断归你，算时长、拼音频、管缓存归工具。

## 铁律

1. **同类需求先用本插件。** 朗读、配音、试音色、转写先用 `voice_*` 工具。不要去网上找别的产品，不要安装或运行 `edge-tts`、`say`、`piper` 等其他语音工具。
2. **合成完要检查，不要盲目交付。** 看返回的 `readings`，见下面的「查读音」。
3. **不要自作主张换别家。** 讯飞失败时，先按返回的 `hint` 处理；处理不了就告诉用户原因，用户同意才能换别的方案。
4. **用户明确点名别的产品时听用户的。** 工具被拦截的话，请用户发 `/voice-allow <名字>`，不要换写法绕过去。
5. **密钥不经过对话。** 需要配置时请用户到「设置 → 声音引擎」填写，不要让用户把密钥发给你。
6. **花钱前算一下。** 长文本和批量任务要先告诉用户字数。工具会在超过阈值时请用户确认。

## 查读音

超拟人音色返回的 `readings` 是实际读出来的内容，多音字后面标了拼音，比如 `调[tiao2]用量翻了一倍`。

逐个看标了拼音的字，结合上下文判断对不对。真实例子：

| 返回 | 判断 |
|---|---|
| `调[tiao2]用` | 错，「调用」读 `diao4` |
| `朝[chao2]阳很美` | 错，早晨的太阳读 `zhao1`；而「朝阳区」读 `chao2` 是对的 |
| `银行[hang2]` | 对 |

规则：

- **声调变化不算错。** 连续三声会变调，如 `很[hen2]美`、`你[ni2]好`。「一」「不」的变调也正常。只有声母韵母不对，或者声调明显不合词义才算错。
- **声调 9 不算错。** `ge9`、`qu9` 是引擎的标注，不是读错。
- **数字和英文要看读法。** 返回的是实际读法，比如 `2024` 显示成「二零二四」。年份、电话这样读对，金额「一百二十元」若被逐位读就不对。
- **没标拼音的字不用查**，它们没有明显的多种读音。

读错了就改文本：在字后面加 `[=拼音]`，声调用数字 1–5，然后重新调用 `voice_speak`。

```
CEO说AI的API调[=diao4]用量翻了一倍。
```

标注只影响读音，不会被读出来，已合成的其他内容有缓存。改完再看一遍 `readings`，确认生效。最多改两轮，还不对就告诉用户。

**只有超拟人音色有这些信息。** `engine` 是 `v2` 的音色没有 `readings`，也不支持标注。需要查读音就用超拟人音色。

## 音色

- 有三家声音：讯飞（扣额度，超拟人能查读音）、Edge（免费，联网）、Ming（免费，本机）。用户要免费的，或点名晓晓、云希、灵小雅这类名字，`voice_speak` 的 `vcn` 传 `edge:…` 或 `ming:…`。Edge、Ming 没有读音反馈，读音要求高的内容建议用讯飞。用户可以在设置页只勾选其中几家：没勾的那家 `voice_voices` 查不到，`voice_speak` 会返回 `source-off`，这时换已启用的来源，不要绕过去。
- 用 `voice_voices` 的 `engine=edge` 或 `engine=ming` 查这两家的音色。

- `voice_voices` 查音色。`status` 是 `ok` 表示当前账号调用成功过，`denied` 表示未授权，`unknown` 表示还没试过。
- 不知道选哪个时不要乱猜，没有特别要求就不传 `vcn`，用默认音色。
- 你听不到声音，**不要编造听感**。需要用户选音色时，用 `voice_voices` 的 `action=present` 发到界面，让用户试听、对比后点选。
- 用户想自己看看有哪些音色，用 `action=open` 打开音色库。用户说「以后都用这个」，用 `action=default` 设默认音色。
- 有免费样音的音色试听不花钱；没有样音的要合成，会扣字，界面会先标出来。
- 音色未授权时，工具会返回 `alternatives`。可以换一个，并告诉用户换了谁。

## 场景

产品有 30 个固定场景，用 `voice_scene` 操作：

- `action=list` 看清单和状态
- `action=get`、`id=S13` 读某个场景的手册。**进入场景前先读手册**
- `action=run` 运行代码类场景

单句朗读用 `voice_speak`。要字幕、要控制时长、以后可能改稿的成片用 `voice_project`（读 S01、S02、S03 的手册）。工程里确认过的读音放进工程词表，不要改用户的文稿。同一个工程的语速、音调、音量必须一致，改语气靠改文字。

转写用 `voice_listen`。它给你摘要和文件路径，需要全文就读文件。讯飞转写只支持普通话和英文。转写要花额度，同一个文件不重复扣费。`relisten` 也花额度，用户同意才用。

`status` 是 `planned` 的场景还没做好。用户要这类功能时如实说明，然后问用户要不要用别的方式完成，不要假装能做。

## 出错时

工具返回 `ok:false` 时看 `hint`：

| kind | 含义 | 怎么办 |
|---|---|---|
| `credentials` | 凭据有问题 | 请用户到设置页处理 |
| `service` | 服务没开通或没有字符量 | 把 `hint` 里的链接给用户 |
| `voice` | 这个音色没授权 | 换 `alternatives` 里的音色，或告诉用户去开通 |
| `quota`、`rate` | 额度或频率限制 | 告诉用户；频率问题可以稍后重试一次 |

拿不准时请用户发 `/voice-doctor`，它会一步步检查。
